# 에이전트 지침 및 규칙

## 토큰(크레딧) 절약 및 효율적 도구 사용 지침

* **도구 호출 최소화**: 단순 질문이나 이미 기존 대화에 나와 있는 매물 정보를 다시 언급할 때는 스크립트 실행이나 DB 조회 도구를 호출하지 않고 기존 문맥을 활용해 즉시 답변한다.
* **간결한 응답**: 코드 전체 출력이나 장황한 중복 요약을 피해 입출력 토큰을 최소화하고, 변경된 핵심 코드나 중요 결정 사항만 간결하게 보고한다.
* **부분 수정 지침**: 파일 수정 시 파일 전체를 덮어쓰지 말고, 필요한 특정 부분만 타겟팅하여 수정(replace)한다.
* **오류 발생 시 재시도 제한**: 스크립트 실행이나 파일 수정 중 오류가 발생할 경우, 코드를 임의로 고쳐서 2회 이상 재시도하지 말고 에러 메시지와 함께 사용자에게 즉시 리포트하여 지침을 구한다.



## 환각(Hallucination) 방지 지침

* **근거 중심 답변**: 데이터베이스(DB)나 제공된 파일 내에 직접 기술되지 않은 미확인 정보(소유자 성함, 금액 등)는 임의로 추정하거나 유추하여 사실인 것처럼 답변하지 않는다.
* **확인 불가 명시**: 누락된 정보나 불확실한 사실에 대해서는 지어내지 말고 "데이터 확인 불가" 혹은 "사용자 확인 필요" 등으로 솔직히 답변하여 검토를 요구한다.

## 빌드 결과물(APK) 저장 규칙
* 완성된 APK 파일은 빌드 후 반드시 구글 드라이브 동기화 폴더인 `G:\내 드라이브\000.앱공유` 경로에 복사 및 저장하여 배포한다.
* **디바이스 즉시 원격 설치 규칙**: 만약 컴퓨터에 안드로이드 실기기가 USB 디버깅 상태로 연결되어 있는 경우(`adb devices` 상에서 인증된 기기 확인 시), 연결된 기기에 `adb install` 명령어를 사용하여 APK를 즉시 직접 설치한다. 기기가 연결되어 있지 않은 경우에는 기존 구글 드라이브 동기화 폴더 저장 방식으로 백업을 진행한다.
